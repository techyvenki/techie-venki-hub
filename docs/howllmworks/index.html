Why "open weights" is what makes this possible

A model's weights are the billions of learned numbers that are the model. A closed model keeps them behind an API — you send text, you get text, you never see inside. An open-weight model publishes those numbers, usually on a hub like Hugging Face.

Because the weights are public, you can download them, run them offline, inspect them, shrink them, and fine-tune them. That's the only reason a series like this can end each stage in working code instead of hand-waving. If you've ever pulled a model with a few commands and watched it generate on your laptop — you've already used the last step of the diagram below.

What happens inside, one token at a time

Generation is a loop. The model turns your prompt into tokens, pushes them through a stack of identical layers, predicts the next token, appends it, and does the whole thing again — until it decides to stop.

The dashed loop is why long outputs are slow and why the KV cache exists — stage 7.
