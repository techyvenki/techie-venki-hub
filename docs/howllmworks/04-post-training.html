B

The pipeline, and why versions exist

Each stage takes the previous model and specializes it further. Crucially, this whole run sits on top of the base model — so a "new version" is usually the same or a lightly-updated base pushed through fresh post-training, not a rebuild from zero.

A note on the preference stage. Classic RLHF trains a separate reward model from human A/B choices, then optimizes against it. Simpler successors (DPO and friends) skip the reward model and learn straight from the comparisons. And Constitutional AI replaces the human labeler with the model itself applying a written set of principles — alignment from rules rather than from millions of hand judgments.
