The transformer block

A model is one small block, stacked dozens of times. The heart of that block is attention: every token looks at the other tokens and decides which ones matter. It's easier to see than to describe — so click a word.

Attention, live

Pick a word (the query). The arcs show how much it attends to every earlier word. Switch heads to see that different heads learn different jobs, and drag the layer slider to watch a head go from positional to meaningful as you move deeper into the stack.

Greyed, dashed words are in the future relative to the current query — a token can only attend to itself and what came before it. That rule is causal masking, and it's why generation happens one token at a time. Click any word, including a greyed one, to make it the new query and watch the mask move with it.

Illustrative patterns. These reproduce behaviors researchers actually find — previous-token heads, reference resolution, attention sinks on the first token — but the numbers are authored for teaching, not read from a specific model. A real model runs many of these heads at once: Qwen3.8-27B, for example, uses 24 in parallel per attention layer.

B

The block around it

Attention is one half. Each token's result then passes through a small feed-forward network (FFN) that does the "thinking" per token. Both are wrapped in residual connections — a shortcut that adds the input back to the output — and the whole block repeats N times. Stack 64 of these and you have a 27B model.

Where do the numbers being mixed come from? Embeddings — each token ID from Stage 1 becomes a long vector of learned numbers, so "cat" and "kitten" start out close together. Attention then reshapes those vectors using context. That's the entire mechanism; everything else is scale.
