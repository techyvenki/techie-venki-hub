Before any of the hard words — pretraining, distillation, mixture-of-experts — two numbers run underneath all of them: how a model reads text, and how big it is. Type into the first panel, drag the second. That's the whole vocabulary of a model card.

How a model reads: tokens

A model never sees letters. It sees tokens — chunks of text, roughly ¾ of a word each. Common words are one token; rare or long words get chopped into pieces. Watch it happen.

How big it is: parameters & precision

A parameter is one learned number — a weight. "27B parameters" is 27 billion of them. How much disk and memory that needs depends on how many bits you store each weight in. This is the 4-bit / 8-bit / bf16 choice, made concrete.
